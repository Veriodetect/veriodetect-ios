Delete my access and data

Use your individual access code to delete your live-X access and registration records for the same approved email. A deletion receipt removes only the request it belongs to, including any access granted to it.

Expired or revoked codes can still be used for deletion. This does not delete other people’s records or information held independently by X.

My private deletion receipts

Keep these privately if you need to delete a pending or rejected request from another device. Never send them to support or share them in a screenshot.
