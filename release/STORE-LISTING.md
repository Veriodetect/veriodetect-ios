## Description

Explore timing and behavioural patterns in conversations and public X activity.

VerioDetect analyses timestamped data on your device and presents experimental evidence indices with supporting diagnostics. Import or paste a conversation, choose the participant to assess, and inspect response timing and possible behavioural transitions. Import X archive, JSON, CSV or timestamped text to explore posting cadence, bursts and activity patterns.

Features:
- Conversation timing analysis with M0 and M1 handoff diagnostics.
- Experimental M2 posting-behaviour analysis with originals, replies and repost filters.
- Timestamp diagnostics and explanations of the signals behind a result.
- Local saved conversation and M2 result summaries, with native sharing.
- Offline analysis of data already available on your device.

Optional live X retrieval requires manual approval and an individual access code, and is subject to daily limits. Access is not granted automatically. Imported-data analysis does not require live X access.

Results describe patterns in the supplied sample. They do not establish identity, prove AI control or determine whether an account is a bot. Sample strength reflects available evidence, not a probability that a classification is correct.

Conversation text is analysed locally. Requesting live X access sends your registration details to our service; live retrieval sends an account handle through our server to X. See our privacy policy for details.

## Reviewer notes draft

VerioDetect is a locally bundled iOS app. Conversation and imported-X analysis are available without an account and work offline. Live X retrieval is an optional server-backed feature with manual approval and daily quotas.

We will provide a working reviewer access code in the private review credentials field, with adequate quota for review. Do not wait for manual approval: use those supplied credentials. Enter the code under Approved X access, tap Check X connection, enter a public handle and Fetch, then choose an activity filter and Analyze. A failed fetch can consume quota, so contact info@cquestra.com if the reviewer allowance needs attention.

For offline analysis, import the review sample supplied with the final submission, choose a participant, and Analyze. Results are experimental timing/behaviour indicators, not calibrated probabilities of AI authorship.

Account/data deletion: open About, enter the individual access code or private registration deletion receipt, confirm deletion, and tap Delete my access and data. Deleting the reviewer account invalidates its live-X code; imported-data analysis remains available offline.

Before submitting these notes: attach an approved sample file and enter the private reviewer code and review contact information. No reviewer code is included in this draft. Build 121 device acceptance confirmed M2 retrieval, local result persistence across restart and native sharing.
